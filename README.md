# AURIGA

Progetto per hackathon Oracle · AI e dati

Sistema di race engineering sviluppato per un hackathon Oracle, con supervisore multiagente e simulatore endurance.

## Esigenza

Collegare telemetria, regolamenti e simulazioni per esplorare decisioni di gara.

## Contributo

Il progetto integra un supervisore, cinque agenti specializzati, strumenti per telemetria e regolamenti e un’interfaccia React. Lo Strategy Lab collega i parametri scelti dall’utente al simulatore Monte Carlo.

## Stack

Python, FastAPI, React, TypeScript, NumPy, MCP, Oracle OCI.

## Una scelta da raccontare

L’AI usa strumenti di calcolo per la simulazione: la demo espone l’interfaccia e il motore originali del modulo Strategy Lab, con parametri didattici.
